🛒 Smart Grocery List & Inventory Manager

A modern and user-friendly grocery inventory management web application built using React.js. This application helps users manage grocery items efficiently by tracking quantities, prices, stock status, and total expenses in real time.

📌 Features
📦 Inventory Management
Add new grocery items
Edit existing items
Delete individual items
Clear all inventory records
🔍 Search & Filter
Search items instantly by name
Filter items using categories
